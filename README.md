# 网申一键填表助手 (OfferAutofill)

面向中国互联网大厂自研官网（字节、腾讯、阿里、美团等）及通用网申系统的 Chrome 扩展程序（Manifest V3，零构建依赖，解压即用）。

## 核心特性

1. **纯本地资料库（隐私不出本机）**
   - 所有简历信息与站点映射记录保存在 `chrome.storage.local`，支持多套资料版本（如“后端开发”、“全栈开发”）及 JSON 导入/导出。
   - 支持直接粘贴简历纯文本 / Markdown，提供**本地离线快速提取**与**AI 智能结构化解析**两种导入方式。

2. **规则词典优先 + 大模型 API 语义兜底（混合模式）**
   - **第一层（0ms 离线）**：内置 40+ 常见中文/英文网申字段同义词与防歧义规则（如区分“姓名”与“紧急联系人姓名”、“学校名称”与“公司名称”），并自动对齐下拉枚举（如 `本科` → `大学本科`、`全日制` → `统招全日制`、`上海, 北京` → `上海市`）。
   - **第二层（可选 LLM 兜底）**：支持任何 OpenAI 兼容接口（DeepSeek、通义千问、Kimi、OpenAI、本地 Ollama）。调用前**自动脱敏**姓名、手机号、证件号、邮箱等强隐私值，仅发送字段元数据与可用路径，本地安全还原写入。
   - **未命中必填项摘录与越用越准记忆闭环**：每次填表后自动摘出「资料为空」或「未识别」的 `* 必填` 字段并在页面橙框标出；支持在弹窗直接输入「记住并填入」，或在网页补填后一键「📥 读取网页补填并记住」，自动回写个人资料库或保存为跨站通用/站点记忆规则，下次遇到同名字段直接命中。

3. **针对互联网大厂前端框架的工程适配**
   - 兼容 React `_valueTracker` / Vue 受控输入，避免“表面填上但校验报空”。
   - 自动点击展开 Arco / AntD / Semi / Element 等自定义 `div` Portal 下拉浮层并匹配点击选项。
   - 自动识别「教育经历 / 实习经历 / 项目经历」多段区块，支持在填表前自动点击「+ 添加教育经历 / 实习经历」补齐段数。

4. **严格安全边界**
   - 自动跳过 `password`、文件上传与各类短信/图形验证码字段。
   - 填表后以绿框（高置信度）、橙框（待核对）、红虚线（失败）高亮标注，**绝不自动点击最终提交按钮**。

## 安装与加载（Chrome / Edge）

本项目无需 `npm install` 或打包构建，可直接作为已解压扩展加载：

1. 打开 Chrome 地址栏输入 `chrome://extensions/`（Edge 输入 `edge://extensions/`）。
2. 开启右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择本目录：`offer-autofill`。
4. 建议将该扩展固定到浏览器右上角工具栏，并点击扩展弹窗内的 **「简历与设置」** 填写或导入你的求职资料（也可以先点 **「载入示例」** 立即体验）。

## 沙盒试跑与测试

### 1. 在模拟大厂网申页体验
你可以直接用浏览器打开项目中的 `test-bench/mock-bigtech-form.html`，然后点击工具栏插件图标中的 **「⚡ 一键智能填表」**（或按快捷键 `Alt+Shift+F`），再点击页面底部的 **「提交前状态检验」** 验证 React 受控状态与自定义下拉框是否真实写入。
